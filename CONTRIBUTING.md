# Contribuer à MOOO

Merci de votre intérêt pour MOOO. Ce guide s'applique à tous les dépôts publics de l'organisation Mooo-HQ.

## Avant de commencer

- Le projet est en phase de conception : les règles ci-dessous évolueront.
- Pour une évolution importante, ouvrez d'abord une **issue** pour en discuter. Cela évite de travailler sur une modification qui ne serait pas retenue.
- Pour signaler une faille de sécurité, n'ouvrez **pas** d'issue publique : suivez la [politique de sécurité](SECURITY.md).

## Licences

| Dépôt | Licence de vos contributions |
|---|---|
| mooo | Business Source License 1.1 (bascule en Apache 2.0 trois ans après chaque version) |
| mooo-sdk | Apache 2.0 |

En contribuant, vous acceptez que votre contribution soit distribuée sous la licence du dépôt concerné.

## Accord de contribution (CLA)

Toute contribution externe nécessite la signature de l'[accord de licence de contribution](CLA.md). Il permet au projet de faire évoluer la licence, par exemple pour raccourcir le délai de bascule en Apache 2.0, sans devoir recontacter chaque contributeur.

La signature se fait une seule fois, lors de votre première pull request.

## Proposer une modification

1. Forkez le dépôt et créez une branche à partir de `main`.
2. Faites des commits clairs, un sujet par commit.
3. Ajoutez ou mettez à jour les tests et la documentation concernés.
4. Ouvrez une pull request en remplissant le modèle proposé.

## Confidentialité

La confidentialité est au cœur de MOOO. Toute contribution doit respecter ces règles :

- aucune donnée de contenu (mails, messages, mémoire) dans les logs, la télémétrie ou les événements d'usage ;
- rien qui permette de distinguer ou de révéler les données de l'espace perso ;
- aucune donnée réelle ni secret dans les tests, exemples ou captures.

## Langue

Les échanges peuvent se faire en français ou en anglais.
