# Politique de sécurité

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir d'issue publique pour une faille de sécurité.

Utilisez le **signalement privé de vulnérabilité** de GitHub : onglet *Security* du dépôt concerné, puis *Report a vulnerability*. Seuls les mainteneurs voient votre signalement.

Indiquez si possible :

- le dépôt et la version concernés ;
- une description de la faille et de son impact ;
- les étapes pour la reproduire.

## Notre engagement

- accuser réception de votre signalement ;
- vous tenir informé de son traitement ;
- vous créditer dans l'avis de sécurité, si vous le souhaitez.

MOOO traite des données professionnelles sensibles : les failles touchant la confidentialité (séparation pro / perso, chiffrement, droits d'accès, journal d'audit) sont traitées en priorité.
